# 🍅 Pomodoro Timer: Focus Assistant

A minimal and responsive web application designed to boost productivity by implementing the famous Pomodoro Technique (25 minutes of work, 5 minutes of break).

This project was built using standard front-end technologies and is hosted live using GitHub Pages. It was developed with the assistance of the Gemini AI model.

## 🚀 Live Demo

Use the timer right now! It is hosted publicly via GitHub Pages.

🔗 https://drsivamonishkumarg-lab.github.io/pomodoro-timer

## ✨ Key Features

* **Classic Cycle:** Default settings of 25m Work, 5m Short Break, and 15m Long Break.
* **Automatic Transition:** Seamlessly switches between work and break sessions.
* **Visual Countdown:** Clear, real-time display showing the remaining minutes and seconds.
* **Responsive Design:** Optimized for use across desktop and mobile devices.
* **Vanilla JS Implementation:** Lightweight, fast, and framework-free code.

## 🛠️ Built With

* **HTML5:** Structural Markup
* **CSS3:** Styling and Layout
* **JavaScript (Vanilla JS):** Core Timer Logic

*Development Assistance provided by **Gemini**.*

## 📝 Usage

1.  **Start:** Click the main button to begin the 25-minute focus session.
2.  **Focus:** Work intensely on your task until the audio alert sounds.
3.  **Break:** The timer automatically switches to a short (or long) break session.
4.  **Stop/Reset:** Use the controls to pause the timer or restart the current cycle.
